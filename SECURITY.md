# Security Policy

This repository is a verification framework, not an audit.

## Reporting security issues

If an observation may affect:

- inflation
- theft
- fund destruction
- consensus split
- remote crash or resource exhaustion
- privacy
- key recovery
- release integrity

then do not publish exploit-enabling detail publicly.

Open a sanitized issue only if it does not contain:

- exploit payloads
- private keys
- seeds
- live wallet details
- undisclosed vulnerability details
- instructions that enable theft, inflation, or network disruption

## WVP boundary

WVP reports are evidence packs. They are not certifications
that a project is safe.
