# WVP Scoring Model

## Purpose

The WVP score is a compact representation of project reality, not a price prediction and not investment advice.

## Levels

- WVP-0: not verifiable
- WVP-1: existence evidenced
- WVP-2: code and activity evidenced
- WVP-3: build reproducibility passed
- WVP-4: major claims mostly evidenced
- WVP-5: technically strongly verified
- WVP-X: warning; severe contradiction or high risk

## Area Results

Code Reality: evidenced / not_evidenced
Developer Competence: strong / medium / weak / unclear
Build Reproducibility: passed / partial / failed
Claim-vs-Code: consistent / overstated / contradicted
Security Posture: robust / open / critical
Development Dynamics: real / artificial / stagnant
Risk: low / medium / high / extreme
Overall Verdict: verified / partially_verified / not_verified / warning

## Rule

A higher WVP level requires stronger reproducible evidence, not stronger wording.
