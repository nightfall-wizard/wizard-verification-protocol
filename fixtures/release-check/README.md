## Safety rules

Do not add:

- private keys;
- seed phrases;
- wallet secrets;
- API tokens;
- GitHub tokens;
- personal data;
- custody data;
- trading instructions;
- investment advice.

## Boundary

Fixtures are not audits.

Fixtures do not prove legal compliance, binary safety, source-to-release correspondence, reproducible builds, consensus correctness, wallet safety, or investment suitability.
