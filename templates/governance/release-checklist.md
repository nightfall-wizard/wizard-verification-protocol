
# WVP Release Checklist

- [ ] Unit tests pass
- [ ] All WVP checkers pass
- [ ] Release pack passes
- [ ] Release-pack hash refreshed
- [ ] Public report sanitized
- [ ] PROJECT-STATE.md current
- [ ] CHANGELOG.md current
- [ ] Non-audit boundary present
- [ ] No real seed
- [ ] No private key
- [ ] No wallet file
- [ ] No live funds
- [ ] No exploit payload
- [ ] No weaponized reproduction
- [ ] PR opened
- [ ] CI passed
- [ ] Reviewer feedback addressed

Boundary:

This checklist supports release hygiene. It does not certify project safety.
