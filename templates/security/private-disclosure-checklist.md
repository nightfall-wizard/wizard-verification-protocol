# Private Disclosure Checklist

Use this checklist before contacting maintainers privately.

- [ ] Class assigned
- [ ] Severity assigned
- [ ] Evidence captured locally
- [ ] No seed included
- [ ] No private key included
- [ ] No live funds included
- [ ] Public summary sanitized
- [ ] Exploit-enabling detail withheld from public repo
- [ ] Non-audit boundary stated
- [ ] Maintainer contact path identified

Do not commit weaponized reproduction material.
