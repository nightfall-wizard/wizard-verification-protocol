# WVP Evidence Standard

## Evidence Labels

- verified: directly checked by reproducible WVP method
- strongly_indicated: multiple independent signals point to the same conclusion
- plausible: consistent with evidence but not sufficiently proven
- open: unresolved
- speculative: weak support or forward-looking claim
- not_found: searched through a defined path and not found
- not_verifiable: cannot currently be checked with available evidence
- contradiction: evidence conflicts with claim
- limitation: known boundary of the method

## Proof Rule

A claim is not verified unless another person or machine can reproduce the check.

## Negative Evidence Rule

Not found only counts when the search path is defined.

## Contradiction Rule

If public claims and technical artifacts conflict, the report must label the conflict instead of smoothing it over.
