# WVP Evidence Model

## Labels

verified: directly checked by a reproducible WVP command.

observed: seen in an artifact but not fully verified.

not_found: searched through a defined path and not found.

not_verified: present but not independently verified.

out_of_scope: explicitly outside this module.

limitation: known boundary of method, data or implementation.

## Rule

A WVP claim without an evidence label is incomplete.

## Forbidden Shortcut

WVP must not convert observed into verified without a reproducible check.
