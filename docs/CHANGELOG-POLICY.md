
# WVP Changelog Policy

Every material WVP evidence change should be recorded.

## Changelog entries should include

- milestone ID
- date
- summary
- changed evidence areas
- changed checkers
- changed reports
- release-pack refresh status
- non-audit boundary status

## Entry types

- Added
- Changed
- Fixed
- Removed
- Security
- Documentation

## Security-sensitive entries

Do not include:

- private keys
- real seeds
- wallet files
- live funds
- exploit payloads
- weaponized reproduction steps
- undisclosed vulnerability detail

## Boundary

The changelog records evidence work. It does not prove project safety.
