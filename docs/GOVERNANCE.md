
# WVP Governance

This document defines lightweight governance for the Wizard Verification Protocol repository.

## Purpose

Governance keeps WVP evidence work consistent, reviewable, safe, and maintainable.

## Core rules

- Use pull requests for evidence changes.
- Keep public reports sanitized.
- Preserve the non-audit boundary.
- Do not commit real seeds.
- Do not commit private keys.
- Do not commit wallet files.
- Do not reference live funds.
- Do not publish exploit payloads.
- Do not publish weaponized reproduction steps.
- Route security-sensitive observations through private disclosure.
- Refresh the release pack before review milestones.
- Keep PROJECT-STATE.md current.

## Decision model

Routine evidence improvements may be reviewed through normal pull requests.

Security-sensitive material must be held privately until safe to summarize.

## Boundary

Governance improves maintainability. It is not an audit, not a certification, and not proof that Nightfall is safe.
