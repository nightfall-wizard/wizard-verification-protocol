
# WVP Runtime Harness Limitations

The WVP runtime toy harness is deliberately limited.

It does not execute Nightfall consensus code.

It does not validate real blocks.

It does not validate real transactions.

It does not validate cryptographic proofs.

It does not mutate live node state.

It does not spend funds.

It does not test real anonymity.

It does not replace a security audit.

The harness provides safe local regression evidence for WVP-owned checking logic.
