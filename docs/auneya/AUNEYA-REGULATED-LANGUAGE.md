# AUNEYA Regulated-Language Policy

## Allowed language

The following language is allowed:

- research;
- simulation;
- architecture;
- non-value;
- toy model;
- threat model;
- boundary;
- witness-network architecture;
- provable-web research;
- phone-first verification research.

## Blocked language without legal review

The following language is blocked unless a qualified legal review record exists:

- token;
- token sale;
- launch;
- listing;
- airdrop;
- reward;
- earn;
- yield;
- profit;
- return;
- investment;
- market value;
- price;
- staking;
- mining reward;
- payout;
- wallet;
- custody;
- payment;
- exchange;
- broker;
- financial product;
- crypto-asset service;
- public offer;
- admission to trading.

## Context exception

Blocked words may appear only when used as negative boundary language, threat modeling, or legal-review gating language.

Example allowed use:

AUNEYA does not create a token.

Example blocked use:

AUNEYA will launch a token.
