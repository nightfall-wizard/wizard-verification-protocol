# AUNEYA Local Collect Command v0.1

Status: protocol research
Scope: local Termux simulation
Value status: non-value simulation only

## Purpose

This document defines the first local AUNEYA collect command.

The command gives a phone user one Termux command to:

- choose a supported lawful public claim key
- run the local non-value demo
- record a local non-value simulated collection entry
- show the local simulated collection status

./tools/auneya/auneya_local_collect.sh
