# AUNEYA Claim Schema v0.1

Status: protocol research  
Scope: provable web  
Value status: non-value simulation only

## Purpose

This document defines the first machine-readable AUNEYA claim format.

A claim is a specific public digital statement that can be checked by witnesses.

AUNEYA does not claim absolute truth.

AUNEYA verifies specific public digital claims within a lawful boundary.

## Claim Formula

Claim
-> lawful public target
-> evidence requirements
-> expiry policy
-> witness eligibility
-> later witness proof

## Claim Types

Initial claim types:

- `release_reality`
- `build_provenance`
- `download_integrity`
- `website_claim_reality`
- `domain_dns_tls_reality`
- `audit_claim_reality`
- `blockchain_claim_reality`
- `app_store_reality`
- `ai_model_reality`
- `media_file_origin_reality`

## Legal Boundary

A claim is out of scope if it requires:

- private account access
- private messages
- hacked data
- paywall bypass
- credential use
- surveillance of private persons
- unlawful scraping
- access-control circumvention

## Non-Value Boundary

This schema does not create a token.

This schema does not create a reward.

This schema does not create market value.

This schema is not an investment offer.

This schema is not legal clearance.

Legal review is required before any public token launch, listing, sale, transferability or market-value communication.
