# AUNEYA Protocol Charter

Status: working architecture  
Maintainer: nightfall-wizard  
Protocol core: Wizard Verification Protocol (WVP)

## Core Sentence

AUNEYA is an open-source, phone-first network for witnessing the provable web.

It turns public digital claims into witness proofs and Auneya Events.

## Positioning

Bitcoin made money scarce.

Ethereum made ownership programmable.

AUNEYA makes the web verifiable.

## Relationship to WVP

WVP is the technical verification core.

AUNEYA is the long-term network architecture built on top of WVP.

WVP defines how claims become evidence.

AUNEYA defines how phones can participate in a global witness network for the provable web.

## Core Formula

Public digital claim
→ phone witness
→ pulse
→ micro-proof
→ prooflet
→ minute reward entry
→ Auneya Event
→ neya

## Scope

AUNEYA is designed for the provable web.

The provable web means public or lawfully accessible digital reality that can be checked without violating privacy, access controls, laws or platform boundaries.

Examples include:

- open-source releases
- software downloads
- file hashes
- detached signatures
- websites
- public project claims
- domains
- DNS records
- TLS certificates
- public audit claims
- blockchain claims
- app-store metadata
- AI model files
- public media and file metadata

## Non-Scope

AUNEYA must not be used for:

- private accounts
- private messages
- hacked data
- paywall bypass
- credential theft
- unlawful scraping
- surveillance of private persons
- illegal data collection
- access-control circumvention

## Network Principle

Do not mine blocks.

Witness reality.

## Behavioral Principle

Every second should show activity.

Every minute should show a reward entry for valid witness work.

The user must see that their phone is doing something useful.
