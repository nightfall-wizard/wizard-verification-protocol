
# WVP Toy Input Safety Boundary

Toy inputs are intentionally artificial.

They may include:

- small integers
- fake IDs
- fake commitments
- fake digests
- fake block heights
- fake report text
- fake issue metadata

They must not include:

- real wallet data
- real seeds
- private keys
- live funds
- real exploit payloads
- weaponized reproduction steps
- undisclosed vulnerability detail
- instructions to attack a network

Toy inputs are for WVP harness behavior only.

They do not prove Nightfall safety.
