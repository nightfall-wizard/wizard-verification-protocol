
# WVP Maintainer Roles

WVP uses lightweight roles.

## Evidence author

Creates evidence artifacts, reports, templates, and checkers.

## Reviewer

Checks clarity, safety boundaries, reproducibility, and non-audit wording.

## Security triage handler

Routes sensitive observations through private disclosure.

## Release coordinator

Ensures the release pack, checksum, changelog, and PROJECT-STATE.md are current.

## Boundary

Roles improve workflow clarity. They do not create audit status or safety certification.
