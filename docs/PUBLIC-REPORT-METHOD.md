# WVP Public Report Method

The public report is a sanitized summary of WVP evidence.

It may include:

- score
- grade
- evidence areas
- public boundaries
- missing evidence
- non-audit disclaimer

It must not include:

- exploit payloads
- private keys
- seeds
- live wallet details
- weaponized reproduction steps
- undisclosed vulnerability details

The report is designed for public readability without
creating avoidable security risk.
