
# WVP External Review Preparation

WVP-SEC-013 prepares the Nightfall evidence pack for external review.

## Purpose

The goal is to make review requests precise, bounded, safe, and useful.

This step prepares:

- review scope
- reviewer request template
- issue-quality gate
- evidence-gap template
- reviewer-question template
- sanitized security-observation template
- reviewer response log
- non-audit boundary
- safety boundary

## What reviewers should evaluate

Reviewers may evaluate:

- whether evidence files are clear
- whether claims are traceable
- whether limitations are explicit
- whether public reports are sanitized
- whether the release pack is reproducible
- whether the issue templates reduce ambiguity
- whether the non-audit boundary is preserved

## What reviewers should not assume

A WVP review request does not mean:

- Nightfall is audited
- Nightfall is safe
- cryptography is correct
- consensus safety is proven
- vulnerabilities are absent
- market value is implied

## Security handling

Security-relevant observations must use the private disclosure and triage workflow.

Public issues must not include:

- private keys
- real seeds
- wallet files
- live funds
- exploit payloads
- weaponized reproduction steps
- undisclosed vulnerability detail

## Boundary

External review preparation improves review quality. It is not an audit.
