# WVP Security Model

WVP creates reproducible evidence for limited security claims.
It does not certify that a cryptocurrency project is safe.

Core question:

Which critical claim is made, where is it specified,
where is it implemented, and what evidence would fail
if the claim were false?

Security classes:

1. Inflation
2. Theft
3. Fund destruction
4. Consensus split
5. Remote crash or resource exhaustion
6. Privacy break
7. Key recovery
8. Release integrity failure
9. Documentation-to-code mismatch

Rule:

Never call a WVP report an audit unless an actual
independent audit was performed.
