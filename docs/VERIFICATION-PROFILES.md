# WVP Verification Profiles

## consensus-v1

Checks evidence around consensus-critical claims.

Required evidence:

- protocol specification exists
- security policy exists
- supply invariant is specified
- known consensus-risk classes are documented
- negative fixtures exist
- traceability report exists
- local verifier returns a bounded verdict

## release-v1

Checks release integrity evidence.

## wallet-v1

Checks wallet and light-client risk evidence.
