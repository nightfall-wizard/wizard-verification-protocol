# Review Operations Boundary Glossary

Status: Review Operations v1  
Marker: WVP-REVIEW-OPS-V1

This glossary exists so review operations use stable, searchable boundary terms.

Required boundary phrases:

- no Nightfall safety certification
- no cryptographic audit
- no financial advice
- no investment advice
- no custody
- no bounty
- no token
- no paid review
- no market value claim
- no 100% completion claim
- no legal advice
- no consensus-correctness proof

Required process phrases:

- formal GitHub PR review
- formal GitHub approval
- Approve
- Comment
- Request changes
- admin bypass
- protected branch policy

## Meaning

These phrases define what WVP review operations do not claim.

They do not weaken the review process. They make the review boundary explicit, searchable, and reproducible.
