# Review Operations

This directory defines the external review workflow for Wizard Verification Protocol.

The goal is to make review requests repeatable, bounded, unpaid, and easy to execute through GitHub's formal PR review system.

## Documents

- `EXTERNAL-REVIEW-PROCESS.md` — maintainer process for requesting and handling reviews.
- `REVIEWER-CHECKLIST.md` — checklist for independent reviewers.
- `REVIEW-REQUEST-TEMPLATE.md` — reusable review request text.
- `MAINTAINER-RESPONSE-PROTOCOL.md` — how maintainers respond after comments, approvals, or requested changes.
- `REVIEW-OPS-EVIDENCE.json` — machine-readable evidence summary.

## Boundary

This process does not create or imply:

- Nightfall safety certification,
- cryptographic audit status,
- consensus-correctness proof,
- legal advice,
- custody,
- financial advice,
- investment advice,
- token sale,
- bounty,
- paid review,
- 100% completion claim.
