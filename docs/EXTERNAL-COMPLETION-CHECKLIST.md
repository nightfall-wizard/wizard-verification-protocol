
# WVP External Completion Checklist

This checklist defines the external work required after local WVP evidence completion.

## Required external actions

- Open pull requests for completed WVP branches.
- Wait for GitHub Actions to run.
- Confirm required checks are green.
- Review PR diffs.
- Merge accepted PRs.
- Enable or verify branch protection on `main`.
- Require the check `WVP Required Checks / required`.
- Confirm force pushes are blocked.
- Confirm branch deletion is blocked.
- Record reviewer or maintainer feedback.
- Record recurring evidence refresh history.

## 100 percent boundary

A local Termux command cannot honestly mark this project as 100 percent complete.

100 percent requires external GitHub state and reviewer/maintainer actions.

## Safety boundary

This checklist must not include private keys, real seeds, wallet files, live funds, exploit payloads, weaponized reproduction steps, or undisclosed vulnerability detail.

## Non-audit boundary

Completion of this checklist does not certify Nightfall safety.


## Exact safety phrase

The external completion checklist explicitly requires: no real seed, no private key, no live funds, no exploit payload.
