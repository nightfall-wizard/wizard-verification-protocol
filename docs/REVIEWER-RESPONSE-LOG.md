
# WVP Reviewer Response Log

Use this log to track reviewer feedback.

## Entry template

Reviewer:
Date:
Evidence area:
Finding type:
Public-safe summary:
Private detail withheld:
Recommended action:
Status:

## Status values

- received
- needs triage
- accepted
- rejected
- fixed
- deferred
- private handling required

## Boundary

This log tracks review feedback. It must not contain private keys, seeds, wallet files, live funds, exploit payloads, or undisclosed vulnerability detail.
