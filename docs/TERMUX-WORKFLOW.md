# Termux Workflow

## Role

Samsung S8 is the mobile command center.

- Termux writes
- Git manages
- GitHub hosts
- GitHub Actions tests
- GitHub CLI controls
- Markdown specifies
- Rust implements
- JSON carries test vectors
- Reports document

## Secret safety

Never commit:

- tokens
- seeds
- private keys
- wallet files
- node datadirs
- exchange credentials

Use hidden input for tokens: read -r -s TOKEN

## WVP rule

Every claim must be linked to a reproducible artifact, command, test vector, report or explicit limitation.
