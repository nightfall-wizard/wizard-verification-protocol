
# WVP PR Merge Workflow

## Workflow

1. Open the pull request.
2. Confirm branch name and milestone.
3. Confirm GitHub Actions start.
4. Confirm required checks pass.
5. Review changed files.
6. Confirm public reports are sanitized.
7. Confirm release-pack hash is current.
8. Confirm non-audit boundary is preserved.
9. Merge only after checks and review are complete.
10. Record merge in the external completion log.

## Required check

`WVP Required Checks / required`

## Boundary

This workflow documents merge procedure. It does not merge PRs by itself and does not prove project safety.
