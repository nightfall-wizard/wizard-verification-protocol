# WVP-SEC-001 Limitations

This pack does not prove that Nightfall is safe.

Not proven:

- cryptographic soundness
- absence of inflation bugs
- absence of wallet theft bugs
- correctness of every consensus path
- real-world anonymity
- exchange safety
- binary provenance

Required next-level evidence:

1. independent audit
2. real negative test vectors
3. fuzzing corpus
4. reproducible builds
5. signed releases
6. issue-to-regression discipline
7. long-term maintenance history
