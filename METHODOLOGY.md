# WVP Methodology

## Method

WVP uses reproducible checks to transform project claims into evidence-backed verdicts.

## Pipeline

1. Identify project claims.
2. Split claims into atomic statements.
3. Gather evidence from public artifacts.
4. Reproduce what can be reproduced.
5. Mark what cannot be verified.
6. Search for contradictions.
7. Apply the WVP evidence standard.
8. Produce a WVP Reality Verdict.

## Evidence Sources

- GitHub repositories
- pull requests
- commits
- releases
- build processes
- whitepapers
- websites
- roadmaps
- documentation
- blockchain data
- wallet, node and mining data
- public developer statements

## Adversarial Check

For every strong claim, WVP must ask:

- What would prove this claim?
- What would falsify this claim?
- Is the evidence reproducible?
- Is there a simpler explanation?
- Is the project overstating the evidence?
