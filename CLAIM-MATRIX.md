# WVP Claim Matrix

## Purpose

The Claim Matrix breaks project claims into atomic statements and checks each claim against evidence.

## Claim Matrix Fields

- claim_id
- original_claim
- atomic_claim
- source
- required_evidence
- observed_evidence
- reproduction_command
- evidence_label
- verdict
- limitation

## Verdicts

- consistent
- overstated
- contradicted
- not_enough_evidence
- not_verifiable

## Core Rule

WVP does not reward claims. WVP rewards reproducible proof.
